# Campaign GRID landing — two art directions

| | Direction A "Mission Control" | Direction B "The Long Route" |
|---|---|---|
| Feel | dark ops console, product-forward | editorial broadsheet, route storytelling |
| Hero visual | fictional ops board (six jobs, zones, triage) | scroll-drawn campaign route, day one → polling day |
| Type | Instrument Sans + IBM Plex Mono | Fraktur display + IBM Plex Mono |
| Wall | schematic: two deployments + hatching | inverted navy manifesto, roman-numeral clauses |
| Ladder | system readout rows, rust callout for stage 4 | ruled index, rust card for stage 4 |
| Best for | party ops buyers, election agents | candidates, first-time evaluators |

## Ship recommendation
Ship **A** if the primary decision-maker is the agent or party ops lead (it demonstrates capability).
Ship **B** if the primary audience is the candidate (it's more memorable and easier to defend in a
five-minute skim).

## What I would test with real visitors
- Time-to-first-click on the sticky CTA rail.
- Whether the demo-button is noticed inside the hero (both directions repeat it 3×).
- Scroll-drop at the wall section — if visitors disengage there, collapse it earlier.
- On direction B: whether the route map is read as a metaphor rather than literal data.
